# صيغة — محوّل الملفات

تطبيق عربي مبني بـ Next.js. يحتوي على واجهة رفع متعددة الملفات وAPI لتحويل الصور والمستندات والجداول، ودمج ملفات PDF. الملفات تعالج في ذاكرة دالة Node.js وتُعاد للمستخدم دون تخزين دائم مقصود.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000.

## النشر على Vercel

1. استورد المستودع إلى Vercel واضبط Root Directory على `/`.
2. استخدم إعدادات Next.js الافتراضية، ثم Deploy.
3. تأكد من نجاح Build في صفحة Deployments. لا توجد متغيرات بيئة لازمة.

## التحويلات المتاحة

- الصور PNG/JPG/JPEG/WEBP/AVIF/BMP إلى صيغ صور مختارة أو PDF.
- PDF إلى TXT أو DOCX أو Markdown عبر استخراج النص؛ دمج عدة ملفات PDF.
- DOCX إلى TXT/Markdown/HTML، وإنشاء DOCX من TXT/Markdown/HTML/JSON/CSV.
- XLSX/XLSM إلى CSV أو JSON أو TXT من أول ورقة عمل فقط.
- CSV إلى JSON أو XLSX؛ JSON (مصفوفة كائنات) إلى CSV.
- التحويل الدفعي إلى الصيغة نفسها، مع تنزيل ملفات الناتج كأرشيف ZIP.

## القيود المهمة

- حد التطبيق 4 ميجابايت إجمالاً و4 ميجابايت لكل ملف، وحتى 8 ملفات؛ قد تفرض Vercel حدوداً للطلب والدالة تتغير حسب خطة الحساب.
- لا يدعم هذا التطبيق تحويل DOCX إلى PDF أو XLSX إلى PDF، ولا ملفات الصوت والفيديو أو جميع صيغ الملفات. يلزم محرك مثل LibreOffice/FFmpeg على خادم أو خدمة تحويل متخصصة لتلك المهام.
- PDF الممسوح ضوئياً يحتاج OCR غير موجود هنا. استخراج الجداول وتنسيق Word/Excel لا يحافظ بالضرورة على التخطيط الأصلي؛ XLSX يعالج أول ورقة، وقد تُستخدم القيم المخزنة للخلايا ذات الصيغ.
- تتم معالجة الملفات مؤقتاً على خادم التطبيق، لذلك لا ترفع ملفات شديدة الحساسية. لا يوجد تخزين دائم مقصود أو نظام حسابات/طوابير في هذا الإصدار.

## بنية الخدمة

`app/api/convert/route.ts` هو endpoint من نوع POST، ويقبل `files` متعددة و`targetFormat`. لدمج PDFs أرسل `action=merge-pdf`. يعمل على Node.js Runtime في Vercel، وليس Edge Runtime.
