# صيغة — محوّل الملفات

تطبيق عربي أحادي الصفحة مبني بـ Next.js، مع واجهة تحويل وAPI يعمل على Node.js. التحويلات تتم على الخادم مؤقتاً لإرجاع الملف الناتج، ولا يوجد تخزين دائم أو حساب مستخدم.

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000.

## النشر على Vercel

1. ارفع الفرع `build/arabic-cv-maker` إلى GitHub.
2. في Vercel اختر **Add New → Project**، ثم استورد المستودع `abwl41340-dev/cv-maker-arabic`.
3. اترك إعدادات Next.js الافتراضية، واختر جذر المشروع `/`، ثم اضغط **Deploy**.
4. يمكن أيضاً اختيار هذا الفرع كفرع الإنتاج من إعدادات المشروع، أو إنشاء Pull Request ودمجه في الفرع الافتراضي أولاً.

لا تحتاج إلى متغيرات بيئة لهذا التطبيق. Vercel يعيد النشر تلقائياً عند دفع تحديثات إلى الفرع المرتبط.

## التحويلات المتاحة حالياً

- الصور PNG/JPG/JPEG/WEBP/AVIF/BMP إلى صيغ الصور الأخرى أو PDF.
- TXT وMarkdown وHTML وJSON وCSV وXML وDOCX وفق خيارات التحويل الظاهرة للتنسيق الم��تار.
- JSON ↔ CSV، وDOCX إلى نص/Markdown/HTML، والنص إلى DOCX.
- لا يدعم التطبيق جميع صيغ الملفات؛ PDF هنا صيغة إخراج للصور، وليس مدخلاً. ملفات الفيديو والصوت وDOC/XLSX/PPTX وملفات الأرشيف تحتاج محركات إضافية غير موجودة في هذا الإصدار.

## حدود الاستضافة والخصوصية

حد رفع التطبيق 4 ميجابايت للملف، لتجنب تجاوز حدود طلبات دوال Vercel. الملفات تُرسل إلى دالة التطبيق وتُعالج مؤقتاً في الذاكرة؛ لا ترفع مستندات حساسة. لملفات أكبر أو تحويلات صوت/فيديو/Office متقدمة يلزم خادم تحويل منفصل أو خدمة متخصصة، مع مراجعة تكلفتها وسياسة الخصوصية.
